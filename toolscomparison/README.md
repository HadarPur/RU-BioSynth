# Tools comparison

Head-to-head runs of three codon-optimization tools — **BioSynth**, **DNAChisel**, and **COSMO** — on the same input genes, scored on the same metrics.

## Layout

- `BioSynth/`, `DNAChisel/`, `COSMO/` — one subdirectory per tool. Each has its own `pipeline.py` exposing a `run_<tool>(...)` entry point plus thin per-gene wrappers (`MYH9.py`, `SAUR11.py`, `SAUR40.py`). See each subdirectory's `README.md` for tool-specific notes.
- `helper.py` — `find_coding_location(sequence)` locates the CDS from a `*ATG...stop` marker (shared across all pipelines).
- `calculate_cai.py` — normalizes a codon-usage table into relative-adaptiveness weights and computes CAI (shared across all pipelines).
- `compare_tools.py` — orchestrator. Runs every tool on every gene, collects metrics, writes `comparison_results.csv`.
- `comparison_results.csv` — latest comparison output (regenerated by `compare_tools.py`).

Inputs live outside this directory, under `files/<gene_dir>/`:

- `<gene_name>.txt` — DNA sequence with a `*` marker immediately before the start codon.
- `<pattern_file_name>.txt` — one forbidden pattern per line.
- `<codon_usage_file_name>.txt` — tab-separated `codon\tfrequency`.

## Running a single tool on a single gene

From the repo root:

```bash
python toolscomparison/BioSynth/SAUR40.py
python toolscomparison/DNAChisel/MYH9.py
python toolscomparison/COSMO/SAUR11.py
```

Each per-gene wrapper is a few lines calling its tool's `run_*` function with the right inputs. Results land under `toolscomparison/<Tool>/results/<gene_name>/` (the directory is wiped before each run).

## Running the full comparison

From the repo root:

```bash
python toolscomparison/compare_tools.py
```

For every (gene, tool) pair this:

1. Changes into the tool's directory so each tool's `./results/` stays scoped.
2. Invokes `run_<tool>(...)` with the gene's parameters.
3. Collects the returned metrics.
4. Writes `toolscomparison/comparison_results.csv`.

Failures on one pair don't abort the sweep — the row is written with `status=error: ...` and the loop continues.

## Metrics in `comparison_results.csv`

| Column | Meaning |
|---|---|
| `gene` | Gene name (e.g. `OQ689691.1`, `SAUR11`, `SAUR40`) |
| `tool` | `BioSynth`, `DNAChisel`, or `COSMO` |
| `cai` | CAI of the optimized coding region, computed by `calculate_cai.py` from the same codon usage table used as input |
| `non_coding_substitutions` | Positions where the optimized base differs from the original *outside* the coding region (5' UTR + 3' UTR). COSMO is always `0` because it only optimizes the CDS |
| `all_patterns_removed` | `True` if every forbidden pattern from the pattern file has zero occurrences in the final optimized sequence |
| `status` | `ok` or `error: <message>` |

## Adding a gene

Add an entry to the `GENES` list in `compare_tools.py` with `gene_dir`, `gene_name`, `pattern_file_name`, `codon_usage_file_name`, and `species` (used by DNAChisel's `MaximizeCAI`). Also drop a thin wrapper into each tool's directory if you want to run it standalone.

## Adding a tool

Create `toolscomparison/<Tool>/pipeline.py` exposing a `run_<tool>(...)` function that returns:

```python
{
    "cai": float,
    "non_coding_substitutions": int,
    "all_patterns_removed": bool,
    "pattern_hits": dict[str, int],
}
```

Then wire it into `compare_tools.py` (`tools` list and the `run_tool` dispatcher).
